## 视觉方向
- 风格：运动感、轻竞技、可信赖，不走通用白底 SaaS 风格
- 气质：暖色驱动转化，深蓝承接可信度，米白提升呼吸感
- 页面节奏：高信息密度，但通过圆角卡片、彩色分层和大标题建立清晰主次

## 设计令牌
- 主色：`#FF6A3D`
- 深色：`#0F1C2E`
- 成功色：`#2FBF71`
- 警示色：`#F5A623`
- 底色：`#FFF9F1`、`#F6F8FB`
- 字体建议：`Avenir Next`, `Segoe UI`, `Noto Sans SC`, `sans-serif`

## 页面说明
- 首页：突出“今晚快速成局”和规则推荐，首页就是转化入口
- 约局广场：把筛选和列表做成高频浏览页，强调成局概率和距离
- 约局详情：集中展示主理人信用、成员状态和申请 CTA
- 创建约局：压缩操作步骤，并给出系统预测成局率
- 消息中心：优先处理申请结果、补位邀请和开打提醒
- 我的：用信用分、连续到场、成局率强化复约和信任体系

## 默认假设
- 移动端优先，桌面端后续再做适配版
- 当前只覆盖乒乓球 MVP
- 推荐机制以规则推荐为核心，不在 UI 中暴露复杂算法细节
